# Agent Note: 先交付手动任务聚焦，再评估图聚合

Status: proposed

[English](2026-09-22-task-dag-manual-focus.md) | 中文

## 问题

data-agent（数据智能体）用户需要解释结果为何受阻，同时不能遗漏无关分支的失败。在尚未证明阅读收益前，结构压缩会先引入分组身份和混合状态摘要。

## 提议

将手动依赖聚焦作为首个简化切片。已经确认、尚未实现的 [DAG 视图简化规格](../../../../wayfinder/task-orchestration-dag/tickets/G11-dag-view-simplification-strategies.md#answer) 负责行为与验证要求；Task DAG journal 仍是权威。现有活跃 Agent Note 没有这项展示决策的归属记录。

增量实现是纯本地选择器、跨范围依赖说明和范围外异常提示。它复用当前数据、任务详情和现有绘图库，不增加模型调用、持久化或调度。这既服务无需预先分组的临时问数，也保留独立内核与可替换绘图库的方向。

## 考虑过的替代方案

**先做分组折叠**有利于稳定的数据工程流水线，但需要先处理跨组关系与混合验收状态，而重复检查分组的使用证据尚未确立。

**单层聚焦并逐层展开**能限制初始密度，但为了发现远处的原因和影响，需要额外导航与展开状态。

**把无关失败固定放入图内**能直接显示异常，但削弱用户所选依赖范围的含义和稳定性。图外异常摘要保留显式导航。

## 验收标准

G11 规格定义精确成员、省略量、异常、身份保持和失败用例。实现者必须提供规定的纯函数、浏览器与无密钥当前视图证据；本次规划变更不声称任何运行时或规模测试结果。

## 风险

中心任务仍可能关联大部分全图。结构摘要与扩展筛选保留为 G11 中具名的后续票据，渲染规模优化单独依据测量决定。首版放弃的是自动压缩，不是真实依赖或失败信息。
