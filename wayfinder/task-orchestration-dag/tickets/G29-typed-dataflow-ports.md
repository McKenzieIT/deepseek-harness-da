## Question

When should lightweight named outputs evolve into typed input and output ports with schema compatibility checks?

Define port identity, required/optional inputs, schema ownership, cardinality, reference types, compatibility, conditional outputs, adapter behavior, schema evolution, and whether ports remain planning metadata or become workflow compilation. The first release stores output names, producer Attempt, evidence/artifact references, assurance, and downstream references without copying large values.
