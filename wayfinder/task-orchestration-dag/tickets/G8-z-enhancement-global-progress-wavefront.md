## Question

Should a later release add a global progress wavefront, or stop at local node and edge transitions?

Compare completed-path, active-inflow, and pending classes against visual load across parallel branches, mixed executor lifecycles, interruptions, reduced motion, and dense graphs. The result must not imply stronger execution truth than the Plan and Attempt state provides.
