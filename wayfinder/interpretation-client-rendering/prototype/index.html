R4 原型 · INTERPRETATION 图表渲染（DSH-UI · 显示数值开关 · 模拟对话）

PROTOTYPE — throwaway. 每图直接渲染启发式选定的类型（T9/T10 默认触发校验器降级 → warn + 回退 bar）。每图卡片内有"显示数值"开关（自写 valueLabelsPlugin · afterDatasetsDraw 顶层叠数值药丸，>8 点不叠）+"仅数据"（DSH 真实表格 + 复制 TSV）。hover tooltip、legend 可点 toggle。用真实 --dsw-alias-* token。非生产；无构建；需联网（仅 Chart.js CDN）。数据为 K11 语义层锚定样本。

启发式（system prompt，语义层词汇）：metric+类别维→bar（长标签→h-bar）｜metric+时间粒度(ds)→line/area｜2 metric→scatter｜metric+≤8值维+占比→doughnut｜3 metric→bubble｜实体×N metric→radar/polarArea
校验器（客户端，按 sniffed 列 kind）：scatter 但 <2 数值列→bar｜doughnut 但 >8 类→bar｜line/area 但 x 非日期/序数→bar｜bubble 但 <3 数值列→bar｜radar/polarArea 但非"实体×N metric"→bar
