## 3. 任务正文

### 目标(一句话)

让 `evidenceClient` 在生产里不再恒为 `null` —— 通证据 UI(B 组总闸):GoalDock / EvidenceSidebar / CoveragePanel / EvalTrajectory / EvalDeltaView / GapPanel / DashboardView / W15 push 全部复活,B→A auto-flip 通电。

### 根因(已核查,见票)

服务端齐全(`packages/data/evidence-query/src/gateway.ts`,`EvidenceQueryGateway extends TypertRemoteService`,namespace `evidenceQuery`,8 个 `@Remote`,bundle:187 已挂)。客户端从未接:

1. `packages/data/evidence-query/package.json` 无 `./typert` / `./remote` 导出(schema-gateway 两者都有)
2. `packages/data/evidence-query/lib/` **只有 `index.js`,没有 `typert.host.js` / `typert.remote-client.js`**(对照:schema-gateway lib 五件齐)
3. `packages/api/remotes/src/client/index.ts:11` 只 import `schemaGatewayRemote`,无 `evidenceQueryRemote`

→ `scope.get('remote.evidenceQuery')` 恒 undefined → `evidenceClient === null` → 上述 7 组件零数据 + auto-flip 永不触发。

### 实施四步

1. **生成 typert 产物**。schema-gateway 的 `lib/typert.host.js` / `typert.remote-client.js` 由 `@deepseek-ai/dsh-typert-generator` 的 **tsdown 插件**(`packages/typert/generator/src/tsdown-plugin.ts`)生成,头部签名 `/* Generated by @deepseek-ai/dsh-typert-generator from FaceModel — do not edit. */`。**先 trace schema-gateway 怎么挂的这个插件**(没找到 schema-gateway 的 per-package `tsdown.config.ts`,可能挂在根 host build 配置或别处),再把同样机制接到 evidence-query。evidence-query 已有 `@deepseek-ai/dsh-typert-protocol` 依赖,缺的是生成器接线。
2. **补 exports**:evidence-query `package.json` 加 `./typert`(→ `lib/typert.host.js`)+ `./remote`(→ `lib/typert.remote-client.js`)+ `files` 含两件 + `.d.ts`。照抄 schema-gateway 的 exports 块。
3. **装配 client**: `packages/api/remotes/src/client/index.ts` 加 `import evidenceQueryRemote from '@deepseek-ai/dsh-evidence-query/remote'` + 装配(对照 schemaGatewayRemote 的装配方式)。验证 `verify-client-packages` gate 仍过。
4. **真实解析路径测试**(票强调):断言装配后 `remote.evidenceQuery` 可解析。**不要只给组件注入 fake client**——W12/W13/W16 都被"组件测试绿、真实路径死"掩盖过。这是本票核心验收。

### ⚠️ 必须同批:DashboardView CSS(否则修好反而变坏)

`DashboardView.tsx:31-49` 用了 `sl-dashboard` / `sl-dashboard__header` / `__title` / `__hero` / `__kpi-row` / `__detail` / `__workspace-link`,**全仓零 `.css` 含这些类**。而 `.tmp/eval-results` 已有 **3 个 distinct runId** = `autoFlipThreshold` **3**(`ui-semantic-layer/src/client/index.ts:157`)→ `evidenceClient` 一非 null,`SemanticLayerShell.tsx:66` 的 `effectiveMode === 'A' && evidenceClient` **立刻为真 → auto-flip 触发 → 渲染一个无样式的 DashboardView**(在 56px rail / 264px sidebar 里溢出)。

**所以本 PR 必须同批补 `DashboardView` 的 CSS module**(参照 `ui-semantic-layer` 其他 `.module.css` 的命名 + 暗色 alias token)。否则:修好 RPC → 按钮变无样式视图,比 null 还糟。
