## 三、请求格式（DashScope 原生）

```jsonc
{
  "model": "qwen-flash",
  "input": {
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "你好，介绍一下你自己"}
    ]
  },
  "parameters": {
    "result_format": "message"     // 固定
    // "max_tokens": 1024, "temperature": 0.7  // 可选
  }
}
```

- 消息在 `input.messages`（不是顶层 `messages`）。
- **传图片**（多模态模型）：把该条 user 消息的 `content` 写成数组：
  ```json
  {"role":"user","content":[{"image":"https://.../pic.jpg"},{"text":"图里有什么？"}]}
  ```

## 五、响应结构（文本 vs 多模态，务必看）

统一骨架：`output.choices[0].message.content` + `usage`。**差异只在 `content` 类型**：

| 模型类 | `content` | 备注 |
|---|---|---|
| 文本类 | 字符串 `"你好！…"` | 直接就是回复文本 |
| 多模态类 | 数组 `[{"text":"你好！…"}]` | 文本片段在数组里；多模态类多为**思考模型**，另有 `message.reasoning_content`（思维链，可忽略）|

**建议：用一个统一函数取文本，业务侧就无需感知差异**：

```python
def get_text(resp: dict) -> str:
    msg = resp["output"]["choices"][0]["message"]
    c = msg.get("content")
    if isinstance(c, str):
        return c                                  # 文本类
    if isinstance(c, list):                        # 多模态类
        return "".join(p.get("text", "") for p in c if isinstance(p, dict))
    return ""
```

```javascript
function getText(resp) {
  const c = resp.output.choices[0].message.content;
  if (typeof c === "string") return c;
  if (Array.isArray(c)) return c.map(p => p.text || "").join("");
  return "";
}
```

用量在 `resp.usage.{input_tokens, output_tokens, total_tokens}`（多模态思考模型的 `output_tokens` 含思维链 token）。

## 六、流式调用（SSE）

加请求头 `X-DashScope-SSE: enable`，并在 `parameters` 加 `incremental_output: true`：

```bash
curl -N -X POST https://pre-aga-ai-gateway.alibaba-inc.com/api/v1/services/aigc/text-generation/generation \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer REDACTED' \
  -H 'X-DashScope-SSE: enable' \
  -d '{"model":"qwen-flash","input":{"messages":[{"role":"user","content":"数到5"}]},"parameters":{"result_format":"message","incremental_output":true}}'
```

每个 `data:` 事件是**增量**片段：文本类 `content` 为增量字符串；多模态类为增量数组。同样用第五节的 `get_text` 逐块取文本拼接即可。末个事件 `finish_reason` 非 `null`（`stop`/`length`），并带最终 `usage`。

> 多模态思考模型流式时：会先刷一大段 `reasoning_content`（思维链）、`content` 为空，最后才出答案。若不想展示思考过程，只取 `content` 即可。

## 七、Python（DashScope SDK）

```python
import dashscope
from dashscope import Generation

dashscope.base_http_api_url = "https://pre-aga-ai-gateway.alibaba-inc.com/api/v1"
dashscope.api_key = "REDACTED"

resp = Generation.call(model="qwen-flash",
                       messages=[{"role":"user","content":"你好"}],
                       result_format="message")
print(resp.output.choices[0].message.content)
```

## 八、错误与限流行为

- 鉴权失败 → HTTP 401。
- 业务/上游错误 → 响应体 `code` 非空 + `message`；HTTP 状态也可能非 2xx。
- **限流**：网关对速率限制**只排队等待、不返回 429**。高负载时请求可能有排队延迟（可达数十秒），但不会因限流被拒。建议客户端超时设置放宽，或优先用流式（更快首字）。
