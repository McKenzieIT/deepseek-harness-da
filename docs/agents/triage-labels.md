# Triage labels

English | [中文](triage-labels.zh.md)

工程技能使用五种规范分诊角色；右列是本 Fork 的实际 GitHub 标签。

| 工程技能角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或判断 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提到某个分诊角色时，使用本表右列对应的 GitHub 标签。若 Fork 后续采用其他标签命名，只修改右列。
